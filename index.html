你能查出凶手是谁吗？

SQL 城出人命了！《SQL 谋杀之谜》既是一门自学 SQL 概念与命令的课程，也是给熟练 SQL 玩家准备的推理游戏——一桩耐人寻味的凶案等着你。

刚开始学 SQL？

这套练习更像「练手」而不是完整教程。如果你完全没用过 SQL，可以先看图文教程。真想系统学 SQL，更适合看一份完整教程，比如 Select Star SQL。
